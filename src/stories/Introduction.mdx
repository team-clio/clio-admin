# Clio Design System

Clio 어드민의 화면을 일관되게 구성하기 위한 디자인 시스템입니다. 밝은 데이터 작업 공간, 절제된 파란색 강조, 높은 정보 밀도를 기본 원칙으로 합니다.

## Principles

- 데이터가 장식보다 먼저 읽혀야 합니다.
- 파란색은 현재 선택, 핵심 행동, AI 상태에 제한적으로 사용합니다.
- 모든 상호작용은 180–440ms 범위의 동일한 모션 언어를 사용합니다.
- `prefers-reduced-motion` 환경에서는 모션을 최소화합니다.
- 컴포넌트는 페이지 문맥과 분리되어 독립적으로 렌더링되어야 합니다.
