# 사이드바 문서 관리 결과

## 완료 상태

완료. 승인된 D1부터 D6까지의 결정과 문서 관리 화면 재설계를 반영했다.

## 완료한 범위

- 사이드바에 `프로젝트` 섹션을 만들고 `문서`와 `프로젝트 설정`을 배치했다.
- 선택한 프로젝트의 문서 관리 전용 화면을 추가했다.
- 상단 전체 폭 업로드 영역과 하단 전체 폭 파일 목록으로 화면을 재설계했다.
- 드래그 앤 드롭과 파일 선택 방식의 복수 파일 등록을 지원한다.
- PDF와 Markdown 이외의 파일을 업로드 전에 제외하고 이유를 안내한다.
- 파일명에서 확장자를 제거한 제목을 기본값으로 제공하고 업로드 전에 수정할 수 있게 했다.
- 여러 파일을 기존 단일 파일 API로 순차 업로드한다.
- 대기, 업로드 중, 완료, 실패 상태와 파일별 오류를 업로드 목록에 표시한다.
- 문서 목록에서 제목, 원본 파일명, 형식, 생성 시각, Agent 동기화 상태를 표시한다.
- 프로젝트 설정의 중복 관리 UI를 문서 수와 전용 화면 링크로 교체했다.
- 프로젝트 미선택, 로딩, 빈 목록, 조회 오류, 삭제 오류 상태를 처리했다.
- 사이드바와 업로드 드롭존의 Storybook 사례를 추가했다.
- `API_UI_CHANGES.md`에 기존 API 계약을 사용하는 UI 동작을 기록했다.
